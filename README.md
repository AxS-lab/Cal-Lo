# Balance · บาลานซ์

แคลอรี่ · ฟิตเนส · สมดุล — เว็บแอปคำนวณแคลอรี่ บันทึกอาหารไทย จับเวลาออกกำลังกาย และติดตามน้ำหนัก

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | แอปหลัก |
| `manifest.webmanifest` | ข้อมูลสำหรับติดตั้งเป็นแอป |
| `sw.js` | ให้แอปเปิดได้ตอนออฟไลน์ |
| `icons/` | โลโก้และไอคอนแอป |

## อัปเดตเวอร์ชัน
แก้ไฟล์แล้วเปลี่ยน `VERSION` ใน `sw.js` ทุกครั้ง เครื่องที่ติดตั้งไว้จะได้โหลดของใหม่

ข้อมูลผู้ใช้เก็บใน localStorage ของแต่ละเบราว์เซอร์ ใช้ปุ่ม "สำรองข้อมูล" ในแดชบอร์ดเพื่อย้ายเครื่อง
